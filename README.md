# ESCUCHÁ ARGENTINA — GitHub Pages

## Publicar desde GitHub (sin instalar programas)

1. Descomprimí el ZIP en tu computadora.
2. Abrí tu repositorio en GitHub → **Add file → Upload files**.
3. Arrastrá el archivo **index.html** y la carpeta completa **videos** (con sus 5 MP4). También podés añadir `.nojekyll` y `README.md`.
4. Confirmá con **Commit changes**. Esperá a que terminen de subirse todos los archivos antes de confirmar.
5. Entrá en **Settings → Pages** y elegí **Deploy from a branch → main → / (root)**.

**Importante:** mantené los videos dentro de la carpeta `videos` con los mismos nombres; de lo contrario, los reproductores no encontrarán sus archivos.

Los cinco videos originales se sirven desde GitHub Pages. Los audios externos necesitan conexión y que sus sitios de origen sigan disponibles. No vuelvas a subir el HTML antiguo de 28 MB.
